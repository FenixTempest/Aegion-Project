# Project Aegis Website

A modern, professional website for Project Aegis - an advanced self-learning AI platform with absolute privacy protection.

## 🎨 Design Features

### Color Scheme
- **Primary Background**: Deep dark navy (#0a0e27)
- **Accent Color 1**: Gold (#d4af37)
- **Accent Color 2**: Cyan (#00d9ff)
- **Text Primary**: Light gray (#e8e8e8)
- **Text Secondary**: Medium gray (#b0b0b0)

### Design Elements
- Smooth transitions on all interactive elements (0.3s - 0.4s duration)
- Gradient overlays for depth and visual interest
- Glassmorphism effects with backdrop blur
- Hover animations with 3D transforms
- Responsive grid layouts
- Professional typography with "Segoe UI" and "Fira Sans" fonts

## 🚀 Usage

1. Open any HTML file in a web browser
2. Navigate between pages using the header menu
3. Hover over buttons and elements to see interactive effects
4. The site is fully responsive - test on mobile devices

## 📝 Customization

To modify colors throughout the site, edit the CSS custom properties in `style1.css` `:root` selector.

To add more pages, create a new HTML file following the same structure as existing pages and update the navigation menu.

## 💡 Features Implementation

- **Smooth Transitions**: All interactive elements use cubic-bezier timing functions
- **Gold & Cyan Accents**: Used throughout for visual consistency and hierarchy
- **Dark Theme**: Professional dark interface reducing eye strain
- **Gradient Effects**: Linear and radial gradients for depth
- **Glassmorphism**: Modern blur and transparency effects
- **Shadow Effects**: Layered shadows for elevation
